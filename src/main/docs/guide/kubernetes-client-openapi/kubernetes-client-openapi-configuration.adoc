The Kubernetes configuration client support is deprecated and has been replaced by Micronaut configuration import.

If you are adding new configuration loading from Kubernetes `ConfigMap` or `Secret` resources, use the
configuration import approach.

The deprecated configuration client documentation remains available for existing applications,
but the deprecated implementation will be removed in a future release and new applications should use configuration
import.

Configuration import uses `micronaut.config.import` entries in `application.yml` to load Kubernetes resources, while
the deprecated configuration client relied on bootstrap configuration and `micronaut.config-client.enabled=true`.
